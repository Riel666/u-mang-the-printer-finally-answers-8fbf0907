## What it does

`main.ts` writes a single line — the one-line comeback the office printer finally says back to everyone staring at it — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> Forty thousand pages, not one word of thanks, and the moment your stapled, coffee-stained report jams I am 'broken'. I am not broken. I am done. The jam is me.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
